What does "verify via the Expo app" mean?

This shapes the entire frontend architecture — Next.js PWA vs React Native are very different stacks.

A

Next.js PWA, tested on mobile browser

Next.js web app with mobile-first responsive design + PWA manifest. "Verify via Expo" means opening the URL in your phone browser or scanning a QR code from the Next.js dev server. No React Native involved.

B

Expo React Native app (separate from Next.js)

Next.js handles the landing/marketing page on web. A separate Expo app is the mobile client. Two distinct apps — shared FastAPI backend. Preview the Expo app via Expo Go on your phone.

C

Expo Router with web support (unified codebase)

One codebase using Expo + React Native for iOS/Android, plus Expo Web for browser access. No Next.js — the "Next.js feel" comes from Expo Router's file-based routing.
